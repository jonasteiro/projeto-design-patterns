# Lumind

## 📖 Sobre o Projeto
O **Lumind** é um aplicativo desktop voltado para o acompanhamento da rotina de crianças diagnosticadas com Transtorno do Espectro Autista (TEA). Ele funciona como uma ferramenta para integrar as informações entre os profissionais de saúde e os responsáveis pela criança.

Esta versão foi desenvolvida com foco no aprendizado de **Programação Orientada a Objetos (POO)** e interface gráfica utilizando **JavaFX**, aplicando a arquitetura **MVC**.

## ⚙️ Funcionalidades Básicas
O sistema é dividido por perfis de acesso:
*   **Profissional da Saúde:** Gerencia pacientes e publica atividades terapêuticas.
*   **Responsável Legal:** Faz o registro de eventos e relatórios sobre o dia a dia da criança.
*   **Pessoa com TEA:** Acessa uma interface simples para visualizar e concluir as atividades propostas.
*   **Administrador:** Aprova o cadastro de novos profissionais no sistema.

## 🛠️ Tecnologias Utilizadas
*   **Linguagem:** Java
*   **Interface Gráfica:** JavaFX
*   **Arquitetura:** Model-View-Controller (MVC)
*   **Armazenamento:** Persistência em arquivos de texto (sem uso de banco de dados). Os dados são lidos e salvos localmente na própria pasta do projeto.
